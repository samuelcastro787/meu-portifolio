Sobre Mim

Sou um Desenvolvedor Back-End focado no ecossistema C# e .NET, dedicado a construir sistemas escaláveis, seguros e eficientes. Atualmente, estou cursando Análise e Desenvolvimento de Sistemas (ADS), aprimorando constantemente minhas habilidades em arquitetura de software, APIs REST, modelagem de bancos de dados (PostgreSQL) e boas práticas de desenvolvimento. Embora meu foco principal seja o Back-End, possuo vivência com tecnologias complementares como JavaScript e Node.js, além de ferramentas de versionamento como Git e GitHub. Gosto de transformar regras de negócio complexas em código limpo, criar projetos práticos e compartilhar minha evolução na tecnologia. Estou em busca da minha primeira oportunidade profissional como Desenvolvedor Back-End para somar em equipes dinâmicas, colaborar em projetos de impacto e continuar evoluindo no desenvolvimento de software.

Este projeto é uma aplicação backend simples desenvolvida com ASP.NET Minimal API e PostgreSQL. O sistema permite aos usuários criar, listar e deletar funcionários, servindo como base para aplicações web maiores.

Controle Financeiro

Conversor de imagem para PDF

Ferramenta web que converte imagens em arquivos PDF diretamente no navegador, sem precisar de backend. Permite selecionar a imagem por clique ou arrastando o arquivo, gera o PDF com o mesmo nome da imagem original e ajusta o tamanho automaticamente para não distorcer a imagem. HTML, CSS, JavaScript, html2pdf.js
